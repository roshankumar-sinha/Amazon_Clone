# Amazon Clone 🛒

This project is a **frontend clone of Amazon's e-commerce website**, created using **HTML and CSS**. The main purpose of this project is to practice and demonstrate web development concepts such as page structure, styling, layouts, navigation bars, product sections, and design.

The project recreates the basic look and feel of Amazon's homepage, including the **navigation bar, search bar, product categories, promotional sections, product cards, and footer**.

### Technologies Used

* **HTML5** – For creating the structure of the webpage
* **CSS3** – For styling, layouts, colors, spacing, and overall design

> **Note:** This is a frontend practice project and does not include real e-commerce functionality such as user authentication, payments, or product purchasing.
